Career Ops

An event-sourced job-search pipeline I built for myself and then made public. Applications are entities with derived state; emails are events that mutate it, so status is computed from the record rather than typed in by hand. It ingests Gmail, classifies every message, polls public ATS boards across 87 companies for newly posted roles, scores each one against a written profile using the Anthropic API, and renders a command centre that ranks what to do next by how recently a role was posted.

It is a real system rather than a demo: SQLite with a derived status model, a review queue for anything the classifier is not sure of, ninety-odd tests, and a scheduled daily run. Most of its interesting bugs were cases where the software confidently told me something untrue, which turns out to be the whole problem with automating judgement.
