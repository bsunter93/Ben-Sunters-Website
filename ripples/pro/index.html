Open data

Open data and API

Each published day is released as JSON and CSV under CC BY 4.0: Wikimedia-derived fields only (date, n, round, parent, answer, multiple, z, lag, fluke, p, category). No descriptions and no Google data.

GET /data/index.json

GET /data/{YYYY-MM-DD}.json · .csv

Game files (latest.json, puzzle/{n}.json, reveal/{n}.json, board/) are public so the game works, but they are not open-licensed: they can carry third-party trend signals. Paid work (reports, briefs, Radar) uses Wikimedia-derived measurements only; channels tagged unofficial or unlicensed on the licences table never enter it. The hash-chained ledger.json lets anyone verify past puzzles.
