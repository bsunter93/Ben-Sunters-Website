Staffing Math

Privacy

Updated 7 November 2026

Staffing Math is a calculator that AI assistants such as Claude, ChatGPT and Gemini can call. It has no accounts and no sign-in. It works out the answer to each request, sends it back, and keeps none of the numbers it was given.

I'm the developer, and this page describes exactly what the hosted server at staffing-math.vercel.app/mcp does. If any of it turns out to be wrong, tell me and I'll correct it.

What a request contains

Your assistant decides when to call Staffing Math and what to send. A request holds the numbers a calculation needs, such as weekly volume, minutes per case, shrinkage, headcount, attrition, time to hire, calls per hour or a service level target. The server reads them, does the arithmetic and returns the result. It doesn't receive your conversation. Some assistants attach a little metadata of their own, such as a language setting or a rough location. The server doesn't read it or keep it.

The server stores no inputs and no results. Each request is answered and forgotten.

What I count

Each request adds one to a tally. The tally records three things:

  • The day, in UTC.
  • The app that called, taken from the first word of the request's user agent, for example openai-mcp. The rest of the user agent is dropped. When an app sends its name on connecting, that name is tallied too.
  • What was asked for: connecting, listing the tools, which tool ran, or loading the hiring plan chart.

The tally never holds the numbers you sent, the answers, IP addresses or anything about you. The totals are public at staffing-math.vercel.app/stats, so you can see everything I see.

Copies you run yourself, from GitHub or as a desktop extension, count nothing.

Who else handles a request

  • Vercel hosts the server. Its platform keeps request logs, which on this plan last about an hour. If a request fails, the error is written to that log. See Vercel's privacy notice.
  • Upstash stores the tally described above. See Upstash's privacy policy.
  • Your assistant holds your conversation under its own privacy policy. Staffing Math doesn't change what Anthropic, OpenAI or Google keep.

Sharing

No data is sold, rented or shared with anyone beyond the two services above, which run the server and store the tally.

AI and machine learning

Staffing Math uses no AI model. Every answer is ordinary arithmetic from the engine behind my Operating Model Simulator, and the code is open source on GitHub. Nothing sent to it is used to train any model.

How the data is protected

In transit. The server answers over HTTPS only.

Retention and deletion. Inputs and results are gone once the reply is sent. Hosting logs expire after about an hour. The tally holds no personal data and is kept until I delete it.

Incident response. If you find a security problem, email sunterbb@gmail.com. I will acknowledge it, fix it, and describe the fix on this page.

Removing it

Remove Staffing Math from your assistant's connector or app settings at any time. Nothing about you stays behind on the server.

Children

Staffing Math is a workforce planning tool and is not directed at children.

Changes

If the server ever starts doing something this page doesn't describe, this page will change first, with a new date.
