Goal Seek: Checked Answers

Privacy

Updated 12 October 2026

Goal Seek: Checked Answers finds the value of one cell that makes a formula reach a number you choose. It works entirely inside the spreadsheet you open it in. Nothing is sent anywhere. There is no server behind it, no account and no database, so there is nothing for me to collect.

I'm the developer, and this page describes exactly what the add-on does. If any of it turns out to be wrong, tell me and I'll correct it.

What it asks for

The add-on requests two permissions, the narrowest ones that let it work:

  • View and manage spreadsheets that this application has been installed in (spreadsheets.currentonly). This lets it try values in the input cell you choose and read the result cell. It covers only the spreadsheet you have open. It can't see any other file in your Drive.
  • Display and run third-party web content in prompts and sidebars inside Google applications (script.container.ui). This is what lets it show its sidebar. Everything in the sidebar is part of the add-on itself. It loads nothing from anywhere else.

It never asks to connect to an external service.

The add-on has no server of its own and makes no network requests. There is no address your data could be sent to.

What happens when you press Find the value

  • It first checks that the result holds still: it changes the input cell once, puts it back, and reads the result twice. If the result moved on its own, it says so and stops.
  • It writes trial values into the input cell you chose, lets the spreadsheet recalculate, and reads the result cell. You'll see the input cell change while it works.
  • When it finds an answer, it writes that answer once more and reads the result again to check it.
  • It tries a range of values around the answer to look for other answers, the same way.
  • It puts your original value back. Your sheet only keeps a new value when you press Apply, and Undo puts the old one back.

What is stored

The last setup you used: the two cell addresses and the target value. It is saved in this spreadsheet's own add-on storage, so the fields are filled in the next time you open the sidebar in that file. It stays in the file and nowhere else.

What I collect

Nothing. There are no analytics and no error reports, and the add-on writes no logs. I can't see your spreadsheets, your cells or your results.

Sharing

There is nothing to share. No data is sold, rented, transferred or disclosed to anyone, because none is collected.

AI and machine learning

The add-on uses no AI or machine learning model and connects to no AI service. The search for an answer is ordinary arithmetic that runs in Apps Script. No data obtained through Google APIs, including anything in your spreadsheet, is used to develop, improve or train any AI or machine learning model.

How the data is protected

Access control. The add-on runs inside Google Apps Script under your own account, with access to the open spreadsheet only.

No transmission. The add-on makes no outbound requests, so there is nothing to encrypt in transit and nothing that leaves Google's infrastructure.

Encryption at rest. Your spreadsheet and the saved setup are stored by Google in your account, under Google's own encryption.

Retention and deletion. Trial values exist only while a run is in progress. The saved setup is replaced by each new run, and it goes with the file if the file is deleted.

Incident response. If you find a security problem, email sunterbb@gmail.com. I will acknowledge it, publish a corrected version, and describe the fix on this page.

Google API Services User Data Policy

Goal Seek: Checked Answers' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can remove the add-on at any time from Extensions > Add-ons > Manage add-ons in Google Sheets, or revoke its access from your Google account permissions page. Revoking access takes effect immediately.

Children

The add-on is a tool for working with spreadsheets and is not directed at children.

Changes

If the add-on ever starts doing something this page doesn't describe, this page will change first, with a new date.
